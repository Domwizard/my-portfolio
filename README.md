# Личное портфолио на Django

Современный, адаптивный сайт-портфолио для разработчика. 

## Технологии:
- Python 3
- Django
- SQLite (база данных)
- HTML/CSS (кастомный дизайн, Glassmorphism)
- JavaScript (анимации, темная тема)
- Bootstrap 5 (сетка)

## Особенности:
- Управление контентом через админку (Jazzmin).
- Темная и светлая тема (сохраняется в браузере).
- Адаптивный дизайн для мобильных устройств.
- Детальные страницы для каждого проекта.
- Кастомная панель управления.

## Как запустить локально:
1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его: `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Сделайте миграции: `python manage.py migrate`
6. Запустите сервер: `python manage.py runserver`
